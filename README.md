# 컷포인트 분할기 (Video Splitter)

동영상에 분할 지점을 찍으면, 그 지점을 기준으로 영상을 여러 개로 나눠 저장해 주는 웹 앱입니다.
분할 지점을 2곳 찍으면 영상이 3개로 나뉘고, 파일 이름은 원래 이름 뒤에 `_번호`가 붙습니다.

```
게임용.mp4  →  게임용_1.mp4, 게임용_2.mp4, 게임용_3.mp4
```

영상은 브라우저 안에서만 처리되며 서버로 업로드되지 않습니다.

## 기능

- 동영상 끌어다 놓기 / 파일 선택 (MP4 · MOV · WebM · MKV)
- 미리보기 재생과 썸네일 타임라인
- 현재 재생 위치에서 분할 (`S`) 또는 시간 직접 입력 (`01:23.500`)
- 분할 지점 드래그로 이동, `Delete`로 삭제
- 구간별 미리 재생, 개별 저장 / 모두 저장
- 저장할 이름 변경 가능
- 분할 방식 선택
  - **정확하게**: 지정한 프레임에서 정확히 자름 (재인코딩, WebCodecs 필요)
  - **빠르게**: 인코딩 없이 복사해서 원본 화질 그대로, 컷은 가까운 키프레임에 맞춰짐

## 단축키

| 키 | 동작 |
| --- | --- |
| `Space` | 재생 / 일시정지 |
| `S` | 현재 위치에서 분할 |
| `←` `→` | 0.1초 이동 |
| `Shift` + `←` `→` | 1초 이동 |
| `Delete` | 선택한 분할 지점 삭제 |

## 실행 방법

빌드 과정이 없는 단일 HTML 파일입니다.

- `index.html`을 브라우저로 바로 열거나
- GitHub Pages로 배포하면 됩니다. (저장소 Settings → Pages → Branch: `main` / root)

Chrome 또는 Edge 최신 버전을 권장합니다. ("정확하게" 방식은 WebCodecs API를 사용합니다.)

## 저장 형식

| 원본 | 저장 |
| --- | --- |
| MP4, MOV | `.mp4` |
| WebM, MKV | `.webm` |

## 사용 기술

- 순수 HTML / CSS / JavaScript
